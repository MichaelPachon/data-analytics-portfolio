# Análisis de Ventas y Comportamiento de Clientes

## 📊 Descripción

Proyecto práctico de Data Analytics desarrollado para analizar el comportamiento de ventas y clientes a partir de un conjunto de datos de comercio electrónico.

El objetivo es transformar datos operativos en información útil para identificar tendencias, medir el desempeño del negocio y generar hipótesis que puedan apoyar la toma de decisiones.

> Los datos utilizados en este proyecto son sintéticos y fueron creados con fines educativos y de construcción de portafolio.

---

## 🎯 Objetivo del análisis

Responder preguntas como:

- ¿Cuánto se está vendiendo?
- ¿Cuántas órdenes y clientes existen?
- ¿Cuál es el ticket promedio?
- ¿Qué ciudades presentan mayor volumen de ventas?
- ¿Qué productos tienen mayor participación?
- ¿Cómo se comportan los clientes?
- ¿En qué etapa del funnel se pierden usuarios?
- ¿Qué oportunidades de negocio pueden identificarse?

---

- SQL

---

## 🔎 Análisis realizado

### Ventas y clientes

Se calcularon:

- Ventas totales
- Órdenes
- Clientes únicos
- Ticket promedio
- Ventas por ciudad
- Ventas por producto

### Funnel de Ecommerce

Se analizó el recorrido:

`page_view → view_item → add_to_cart → purchase`

Para esto se utilizaron conceptos de SQL como:

- `DISTINCT`
- `JOIN`
- `CTE`
- Funciones agregadas

### Retención y cohortes

Se exploró el comportamiento de los clientes a través del tiempo para identificar patrones de retención y generar hipótesis de negocio.

---

## 💡 Enfoque

El análisis sigue una estructura orientada a negocio:

**Pregunta → Datos → Preparación → Análisis → KPI → Insight → Recomendación**

La intención no es solamente presentar números, sino comprender qué historia cuentan los datos y qué decisiones podrían derivarse de ellos.
