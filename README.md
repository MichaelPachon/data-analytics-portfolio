## 📊 Proyectos

### 01 — Análisis de ventas y comportamiento de clientes

Proyecto de análisis orientado a comprender el comportamiento de ventas y clientes.

**Herramientas:**
SQL · Excel

**Análisis realizado:**

- Ventas totales
- Clientes únicos
- Número de órdenes
- Ticket promedio
- Ventas por ciudad
- Ventas por producto
- Comportamiento de clientes
- Identificación de oportunidades de negocio

**Objetivo:**

Transformar los datos de ventas en información que permita identificar tendencias, oportunidades y posibles acciones para mejorar el desempeño del negocio.

---

### 02 — Funnel de Ecommerce

Análisis del recorrido de los usuarios dentro de un proceso de compra.

**Etapas analizadas:**

`page_view → view_item → add_to_cart → purchase`

**Conceptos utilizados:**

- CTE
- DISTINCT
- JOIN
- Agregaciones
- Usuarios únicos
- Tasas de conversión

**Objetivo:**

Identificar en qué etapas del proceso se pierden usuarios y dónde pueden existir oportunidades de mejora.

---

### 03 — Retención y análisis de cohortes

Análisis del comportamiento de los clientes a través del tiempo.

**Conceptos utilizados:**

- Retención
- Cohortes
- Clientes recurrentes
- Comparación temporal
- Hipótesis de negocio

**Objetivo:**

Comprender cómo cambia el comportamiento de los clientes y detectar oportunidades para mejorar la retención.
